## 本次实现

1. 可靠收藏和可携带的 Markdown：收藏保存选中文本及明确的原始片段证据；不能伪造 AI 改写为原文。过期证据显式提示，不静默排除。导出保留有版本的来源映射，导入重映射 UUID/引用并保留视频 URL 和时间点。
2. 笔记互联：安全完整 Markdown 渲染，支持内部链接/反链、未解析提示、标签与笔记书签、Markdown 文件夹导入/导出、版本浏览恢复。引用图谱由明确链接和已确认关系构成，类型清楚区分，点击可回到笔记。
3. 视频能力：本地音视频与 B 站公开链接使用同一持久任务流程；优先可用字幕，缺少时本地 faster-whisper 转写。保留时间点，支持受管理截图；耗时任务异步执行、显示进度、失败可重试。私人/受限视频失败如实显示，禁止伪造转写或截图。
4. 生成教程支持学习教程/精简摘要等风格，格式和原文依据仍需校验；保留旧版本。个人偏好直接读取，知识和学习经历继续由 mem0 召回。
5. 修复当前代理环境下占位 SDK 构造失败，使真实 mem0 不因无关的环境代理解析而停用；不修改系统代理或用户在线服务设置。
