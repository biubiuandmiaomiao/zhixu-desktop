# 学习记忆与个人偏好的分工

用户已确认实施：个人偏好在 AI 生成前直接读取，不进行向量召回或资料关联；mem0 负责教程知识、已确认关系、复习经历和历史提问的检索。

SQLite 保留原文、完整试卷、准确分数、问答及关系状态。mem0 中的学习经历是可重建的、有来源和时间的记录：关系只收录已确认且有证据的条目；复习只收录已完成的单题表现，不推断长期掌握程度；问答只收录历史问题及引用来源，不把 AI 答案升级为知识。

按 knowledge / relation / review / conversation 区分召回用途。学习经历用于选择讲解重点和出题方向，事实回答仍须引用原始资料。问答及出题前按需同步学习经历；同步或检索失败时继续使用原文和本地偏好，并显示提示。当前来源范围与收藏范围必须在检索前过滤；过期、未完成同步及已删除记录不得参与召回。

偏好、目标和用户确认的进度保留现有管理入口和版本替代。问答、教程生成及出题直接读取当前有效项。旧版 mem0 personal 记录在升级时离线清理，保留 SQLite 原始条目。

删除或修改来源时清理对应知识及派生学习经历；拒绝关系时清理该关系记忆。不同模型空间隔离、同步去重、失败重试及原生历史清理继续保留。界面显示各类学习记忆数量以及生成时使用的学习经历数量。

验收以真实 mem0、Qdrant、SQLite 和 Electron 为准，外部模型使用本机响应替身，不使用用户密钥测试。覆盖偏好更新与旧索引清理、三类经历召回、作用域、重启、删除、失败降级、十题答案隔离及窗口关闭恢复。
