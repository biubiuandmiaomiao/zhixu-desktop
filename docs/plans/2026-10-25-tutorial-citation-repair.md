# 教程引用修正与诊断

用户已授权实现并以 P19 验证，直接在当前工作区执行。

流程：生成 → 独立保存脱敏草稿与结构化校验错误 → 引用错误时附真实 sources、草稿与错误请求模型修正一次 → 全量复验 → 原有取消/并发编辑保护 → 正文保存。

不使用任意合法 ID 替换；不降低中文、截图或可见引用校验。修正仍失败或网络失败均保留诊断；失败草稿不进入知识库搜索、版本或索引。资料详情以纯文本展示最近 20 次结果；删除资料级联删除。记录 run_id、attempt、content、errors、status、created_at，保留原始来源 ID。

实施顺序：
1. 添加回归测试，验证首次失败留存、精确错误、修正成功/再次失败、修正请求失败和并发编辑保护。运行测试确认失败。
2. Store 新建 tutorial_attempts 表及读写方法；Knowledge 分离校验、至多一次修正、每次留存。Service document 返回诊断，前端以 escaped pre 显示。
3. 运行完整 Python 测试、TypeScript/Vite 构建及 Electron smoke。
4. SQLite 在线备份；在已配置服务上复用 P19 原文与截图真实生成，记录模型调用及引用结果。必要时受控制造一次引用格式错误验证真实修正调用，明确区分自然与注入故障。
5. 构建本机启动器优先使用的发行目录，验证产物。

验收：真实原文/截图未丢失，最终教程引用均为本资料片段 ID；失败草稿可在详情查看；连续修正有上限；取消/编辑期间不覆盖；没有凭据进入诊断。
