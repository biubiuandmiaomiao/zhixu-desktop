# 视频知识桌面应用设计

日期：2026-10-24
状态：预览版 0.4 已按 REA 对比补齐笔记引用、版本、可携带来源和后台媒体处理。真实 mem0 与个人设置直接读取的划分继续保留；范围与验证见 README.md、verification.md 及 audits/2026-10-25-feature-parity.md。

## 目标与边界

面向个人学习的 Windows 独立桌面应用，将 B 站视频转为可编辑教程，支持文本收藏、跨教程知识关联、知识库问答和复习。采用本地优先存储，用户已接受在线 AI API。当前语音转写使用本地模型；在线生成、可选图片理解和向量化会发送所需内容给配置服务，本地存储不代表完全离线。

第一版覆盖单用户、单机使用；不包含团队协作、云同步和完整 Obsidian 插件兼容。支持 Markdown 导入导出。

## 推荐技术路线

Electron + TypeScript 界面，Python 后台负责视频处理和记忆服务，SQLite 保存结构化数据及全文索引，Qdrant 本地持久化向量索引。Markdown 保存可读笔记和教程，SQLite 保存其稳定标识、版本及关系。向量库是可重建索引，不是唯一事实来源。

桌面主进程管理 Python 子进程；通过受限 IPC 暴露操作，界面不直接访问任意文件或执行命令。凭据使用 Windows 凭据保护能力保存，不写入笔记、事件或日志。已验证 Windows x64 目录打包及实际窗口操作。

## 统一记忆底座

0.4 增加确定性的笔记引用索引和历史快照：wiki / Markdown 出链与反链、标签、书签、图谱来自 SQLite，语义相似资料继续经 mem0 召回后由用户确认。链接显示名和文件路径可变化，内部目标身份与删除标记独立保留；历史恢复和可携带导出不会把旧链接误接到新建同名资料。正文 / 原始来源 / 链接快照与后台媒体完成状态在同一业务事务内落盘。这里的内部 UUID 是数据身份，不是参与知识关联的个人编号。

本地媒体通过原生文件选择器准入，公开视频使用明确平台直达链接。后台优先真实字幕，必要时 faster-whisper 转写；FFmpeg 使用本地媒体和受管理输出。文件夹导入导出、模型 / 媒体路径和截图读取有边界，界面不能用通用 IPC 传任意路径。Markdown 转义原始 HTML 再清洗渲染，原文不能变成操作按钮。详见 superpowers/specs/2026-10-25-rea-feature-parity-design.md。

共用内容标识、来源、向量化、检索和关系服务，但保留明确的数据类型：

1. 原始资料：字幕、视频时间点、导入文本、截图。
2. 知识资产：教程、收藏卡片、知识点与关系。
3. Agent 记忆：用户明确表达的偏好、学习目标和经确认的进度。
4. 会话与任务：对话、处理事件、持久化后台任务。

教程内容不自动成为用户指令；助手生成的结论不自动成为用户事实。阅读过某知识点不能直接推断已掌握。复习结果与用户确认用于更新学习状态。

## 核心流程

视频链接 → 验证及获取可用字幕，必要时转写 → 按章节切分并保留时间点 → 生成可编辑教程 → 抽取知识点 → 检索已有资料 → 产生关联建议 → 用户阅读、收藏与提问 → 生成可编辑复习卡。

文本导入与划选收藏进入同一条知识处理链。视频获取失败时保留任务状态，允许重试或导入字幕；不可获取的视频不得显示为处理成功。AI 补充解释与来源原文在数据中区分。

## 存储模型

- sources / source_segments：原始来源、文本分段、视频位置。
- documents / document_versions：教程与导入笔记，包含 Markdown 路径、内容哈希和版本。
- cards：收藏内容及来源定位。
- concepts / concept_mentions：规范知识点、别名，以及出现的具体段落。
- relations：两端实体、关系类型、理由、证据、生成方式、置信度与确认状态。
- memories：偏好、目标、进度等类型；包含用户及知识库作用域、来源、有效状态和替代关系。
- sessions / messages：会话与消息。
- jobs / events：后台任务、尝试次数、完成阶段及错误。
- review_cards / review_events：题目、答案、知识来源与复习表现。

实体均使用持久 UUID，文件移动不改变身份。向量记录关联实体 ID、内容版本、Embedding 模型和维度；更换模型时重建索引，不混用不同向量空间。

## 教程关联

关键词与语义检索产生候选，再判断关系。第一版支持同一知识点、前置知识、进阶、补充案例、内容差异或冲突。前置和进阶具有方向，不能由相似度直接推出。

每条建议解释关联原因，并链接具体段落或视频时间点。自动关系标为待确认，用户可接受、拒绝或手动创建。拒绝结果保留，避免同一版本反复推荐。别名合并和知识点重命名保留原有来源。

原始资料不因相似而自动合并或删除。教程更新后，相应关系标记待复核。全局图谱可视化不进入第一版，先提供相关资料面板和知识点聚合页。

## 检索与问答

用户问题 → 确定当前教程或整个知识库的范围 → 直接读取当前有效个人偏好/目标/自述进度 → 分别召回知识证据和学习经历 → 在所选范围内回链原文 → 在上下文预算内生成回答。跨教程关联及补充资料使用“整个知识库”范围。

知识证据、个人设置和学习经历分别传递；所有参考内容均作为数据，不获得系统指令权限。个人设置只影响表达及重点，学习经历不作为事实依据。回答引用资料段落和视频位置。证据不足时明确说明，资料存在版本冲突时同时展示差异。

不能照搬编码助手“只在会话第一次检索”的策略：学习问答可能每轮切换话题，应按问题与资料版本检索并缓存。超时可退回全文检索，但界面需要显示降级状态。

## 记忆写入与更新

借鉴 F:/memos 的事件落盘、后台抽取、作用域隔离和限量召回。原始事件持久化之前进行敏感字段过滤；记忆抽取前再次检查。API 凭据不进入通用事件管道。

使用知识库及课程 ID 替代编码示例的 git remote 项目身份。明确的“记住”请求写入可管理记忆；自动抽取的偏好与进度作为候选展示。记忆支持更正、删除、暂停记录及导出。

偏好变化时新增版本，并将旧记录标记为已替代，默认检索排除失效记录；保留可审计历史。用户删除时一并清除对应向量、全文索引及派生记忆引用，避免删除内容再次被召回。

## 可靠性与恢复

事件与后台任务先存 SQLite。任务按阶段保存，采用幂等标识避免重试重复创建教程和知识点。后台索引失败不撤销已保存正文，界面显示待索引或失败状态。应用退出时不依赖一次性退出回调完成全部工作，重启后恢复未完成任务。

F:/memos/mem0-lab 中的规则 LLM 与 HashEmbedding 仅作离线流程示范，不作为正式检索实现。按用户明确要求，实际接入 D:/Memo/mem0 下载仓库的 mem0ai 2.2.1，固定提交及许可证见 vendor/mem0/UPSTREAM.json。Memory.add(infer=True) 从教程片段提取事实，原生 Memory.search 召回后回链原始片段；已确认关系、已完成单题观察和历史问题采用 infer=False 保存可核对的记录。个人设置不再进入 mem0。模型传输适配器独立于未修改的上游代码，完整业务资料、题库及关系状态仍由应用维护。细节见 superpowers/specs/2026-10-25-learning-memory-design.md。

同步映射记录内容版本和待处理状态，更换模型时使用独立空间。删除来源时清理向量、原生消息及历史记录，避免失效事实再次参与检索。每次同步最多处理 24 项，并在开始下一项前检查 160 秒预算；中途停止或失败后可继续同步。

## 页面

左侧：知识库、教程、收藏、知识点和搜索。中间：教程阅读编辑与来源定位。右侧：相关资料与 AI 问答。另设复习页面、记忆管理及服务设置页面。

## 验收场景

1. 同一知识点出现在两个教程中，系统给出含具体出处的关联建议；用户能确认或拒绝。
2. 重启应用后，教程、收藏、记忆与处理任务仍然存在。
3. 修改讲解偏好后，新会话采用最新偏好，旧偏好不参与默认召回。
4. 跨教程提问能引用多个来源；无法找到依据时不伪造引用。
5. 删除资料或记忆后，搜索、关联和问答均不再返回已删除内容。
6. API 或索引服务失败时已保存内容可读，失败任务可恢复且不会重复创建资产。
7. 读取教程内容不会触发其中夹带的工具调用或记忆写入指令。

## 每次 10 题的复习与题库

每次复习从当前教程、选定收藏或整个知识库中选择有来源的知识片段，默认生成 4 道单选、3 道多选、3 道简答，题目顺序打乱。每次调用在线模型生成新题，连同来源、答案、解析和评分要点保存为一个可恢复的练习组及题库记录。随机性来自片段抽样、生成种子与题目顺序；同组题目不可重复，近期相同题干应剔除并重试。

题目必须能由引用片段支持。资料太少或模型返回无效题目时不凑题、不保存半组练习，明确提示补充资料或重试。选择题的答案和解析在交卷前不下发到界面。单选恰有一个正确选项，多选至少两个；选项标识唯一，答案不得引用不存在的选项。

单选与多选每题 10 分，多选第一版采用完全匹配计分，漏选或错选均为 0 分；简答按预设评分要点调用 AI 给出 0–10 分、遗漏点及改进建议，并标注 AI 辅助评分。总分 100。AI 评分失败时不生成虚构分数，允许保留作答并重试。

提交后展示正确答案、解析、引用资料和简答评分要点。作答草稿自动保存，重启可继续；已交卷记录再次打开只读，避免重复计分。错题记录影响后续来源抽样权重，但不能仅凭一次错误判定用户长期能力。题库可查看历史题目和成绩，支持按来源删除关联题目。

## 开发顺序

先完成本地资料、收藏和来源管理，再接入视频处理及在线模型；之后完成统一检索、关联建议和引用问答，最后加入 Agent 记忆管理与复习。各阶段保留可验证的完整用户流程。
