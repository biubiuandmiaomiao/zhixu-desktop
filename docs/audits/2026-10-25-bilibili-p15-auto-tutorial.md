# P15 手动导入只显示英文：原因、修复与验证

日期：2026-10-25；交付版本：0.4.3。

## 实际原因

用户指出 `BV1AJen6SEVQ P15 · 2-创建工具` 与已有中文教程不同。只读核对发现，资料正文是英文原声转写，含 38 段时间点来源和 6 张截图；版本历史只有一次 `import`，没有教程生成记录。

旧流程在字幕／ASR 和截图保存后即把任务标为完成，从未继续调用 `Knowledge.tutorial`。阅读页把这份原文也称为“教程正文”，造成导入完成等于教程生成完成的误解。此前 P12/P13 已另行执行 AI 整理，因此显示中文。问题不在于 Whisper 没有把英语强制识别成中文。

## 修复

- 视频链接与本地音视频表单默认勾选“导入后自动生成中文教程”。转写语言仍指原声语言；取消勾选可只保存原文。
- 后台先原子保存原文、来源与截图，再用当前配置的模型生成中文教程；启用截图时传入受管理的图片。任务状态区分素材保存、生成中、教程完成和教程失败。
- 模型失败时保留原始资料和明确错误，允许打开原文。重试复用同一资料、来源和截图，只重做教程，不重新下载或建立重复资料。
- 模型调用不持有任务锁。提交前检查取消／删除和原文版本，SQLite 写入阶段保护检查与保存；取消或用户编辑后到达的结果不会覆盖当前内容。
- 后台线程使用自己的 Store 连接和新建 Provider；凭据仅保留在进程内存，不进入任务选项或数据库。
- 已导入的原文可用“AI 整理为中文教程”直接整理，成功后更新任务状态。阅读标签改为“资料正文”，避免把原文误称为已完成教程。
- 完成后的阅读页仅替换资料区域，保留搜索草稿和焦点。弹窗、忙碌或导航打断时保留待刷新标识，空闲后再更新。

没有接入新的 Skill、MCP 或独立评估系统。

## P15 真实模型结果

通过实际打包程序打开用户已有的 P15，选择“学习教程”并勾选六张截图，使用已配置的 `deepseek-v4.1-flash` 完成一次真实在线生成。

- 中文正文 4,585 字符，其中 1,342 个汉字，包含概述、工具调用过程、关键概念与练习建议。
- 40 处来源引用全部指向该份资料的有效片段。
- 正文插入 6 张已登记截图，没有未知图片编号；实际窗口确认中文正文与图片显示。
- 原来 38 段来源的编号、文字、时间和顺序保持一致；生成前后序列 SHA256 均为 `b633bc2588e2fe41996fbbd9b2339fc7baf24c7768b8d1c56aca245eba938f8d`。
- 版本历史保留原始导入与生成后正文，共两版；任务状态为 `tutorial_completed`。

升级前通过 SQLite backup API 创建 `data/backups/before-auto-tutorial-20261025-182613.sqlite3`。API Key 未读出、展示或写入报告，调用继续走应用现有加密凭据通道。

## 验证与边界

147 项 Python 测试、5 项 Node 路径测试及 TypeScript/Vite 构建通过。新增六项回归先失败后通过，覆盖英文原文生成中文、原文不变、显式关闭自动生成、失败重试不重复导入、取消与并发编辑保护，以及已有资料手动整理后的状态。

开发与打包程序的原 mem0／十题 smoke、笔记 smoke、新媒体教程 smoke 均通过。新 smoke 使用真实 Electron、FFmpeg 英文内嵌字幕及截图，模型为本机测试服务：首次故意返回无效引用，确认原文保留，第二次成功；另验证阅读原文期间自动更新中文正文且搜索草稿／焦点不丢失。独立复查补充验证重启重试、生成期间删除与弹窗／忙碌／导航打断后的恢复。

本次真实在线结果限于 P15 教程。有效引用和汉字数量不证明全部知识判断正确；原声转写、截图中的英文、代码和专有名词保留供核对。自动整理会使用配置的在线模型，增加调用时间与费用；无模型或调用失败时仍可保留原文。
