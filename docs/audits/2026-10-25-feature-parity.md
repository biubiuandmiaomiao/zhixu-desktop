## 验证与工程修复

- 完整 Python 套件 123 项、Node 数据路径 5 项通过；依赖一致性、TypeScript / Vite、PyInstaller 后端及 Electron Windows 目录打包通过。
- 开发与打包窗口的两套 smoke 均通过：旧 mem0 / 十题 / 草稿 / 删除；新安全 Markdown / wiki / 块定位 / 回链 / 标签 / 书签 / 键盘图谱 / 历史恢复 / 原生对话框文件夹往返 / 收藏出处修复。
- 使用 Windows 语音合成的实际音频制作视频，真实 Whisper 识别闭包 / 装饰器两段英文，真实 FFmpeg 产出截图。打包窗口移除系统 FFmpeg 的 PATH 后仍通过；权重缓存于 D 盘 `data/models`，未塞入应用包。
- 独立复查提出并修复：导入批次误绑同名旧资料、历史 / 导出丢失已删除身份、字幕失败无法回退、中文笔记超旧文件上限、版本列表读取完整大正文、长字幕超旧元数据上限。回归均先失败后通过；实际打包后端另通过 10,001 段来源和时间的往返。
- 单媒体最多 1 GiB / 4 小时；正文 200 万字符，来源最多 50,000 段。文件夹最多 500 文件 / 合计 40 MB、单文件 24 MB；单次教程生成最多 8 万字。
- 业务库备份 `data/backups/before-rea-parity-20261025-161629.sqlite3`，完整性检查通过。自动化使用独立 `.test-data`，没有读取用户 API Key 或用户 Obsidian vault。

## 新版 REA 运行与边界

新版 ASAR 有 33 个相关文件，21 个 JS 文件解析、0 个解析失败；10 个 renderer IPC 发送都有静态匹配处理器。语义图仍为 partial，保留 6456 条 unknown，静态匹配不证明授权或运行时安全。

REA 实际启动隔离 `--data-dir` 的打包 EXE，六个声明动作完成：等待启动、打开笔记、点击块链接、打开版本、关闭版本、打开图谱。记录 `ev_14603352422b247e14ca1b0b69bec90116fd21ae9a3407c0601ccb3aa3d06aae`，工具随后清理自有程序。主进程钩子出现 `hook_conflict`，所以 **IPC / 生命周期时间线不可用**；没有声称捕获这些事件或用零事件推断无通信。完整功能断言以独立 Playwright 实际窗口测试为准。

机器本地证据在忽略的 `artifacts`：`rea-bilinote-evidence.json`、`rea-obsidian-evidence.json`、`rea/root-before.json`、`rea/zhixu-after.json`、`real-asr.json`。稳定版本、哈希、Evidence ID 和结论保存于本报告与分项报告，机器产物不随 Git 自动发布。
