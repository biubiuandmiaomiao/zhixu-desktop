# 0.4.4：源码复查与生成校验修复

本次按用户要求复查导入、教程生成、重试和图片导出的实际代码。未新增 MCP、模型服务或独立评估系统。

## 已复现并修复的问题

1. **运行中任务被历史列表隐藏。** `tutorial_running` 曾从最近 200 条任务中查找，较旧的活动任务可能漏掉，允许重复生成。改为按资料与活动状态直接查询数据库，不以界面历史列表作为判断依据。
2. **全英文结果被报告为中文教程。** 原实现只提示模型使用中文，未检查返回内容。现在从 Markdown 的可见文字中检查中文说明；引用标记、代码、隐藏注释和图片标签不算说明。完全没有中文说明时取消保存，走原有失败／重试流程。此检查只拦截明显不符的输出，不证明语言或知识质量。
3. **隐藏或错误上下文的引用被接受。** 只在代码、注释、图片标签、双链名称或裸 URL 中出现的来源标记，不再充当原文出处。正常正文、强调文字及完成的链接／代码之后的可见引用仍可使用。代码中的示意编号不会误使正常教程失败。
4. **引用式截图绕过校验或导出遗漏。** 解析实际图片及引用定义，校验受管理截图编号，并规范化 `frame:`、嵌入导出和去重。保留转义标签、列表／引用容器前缀，只改目标地址。未知图片拒绝处理；已识别为图片但无法准确定位的特殊行内语法明确报错，避免成功保存后图片损坏。

图片体积仍在构建完整正文前检查；重复使用一个引用定义只嵌入一次。原文、来源身份和笔记历史的保存边界保持不变。

## 验证

上述问题均有失败后通过的回归。覆盖 200 条较新历史任务、英文结果、隐藏引用、前后端引用渲染的一致性、正常代码／链接邻接引用、三种引用式图片、转义括号标签、容器定义、图片去重及大小限制。独立复查使用实际前端渲染器对照引用结果。

`scripts/media-tutorial-smoke.cjs` 使用真实 Electron、FFmpeg 英文字幕和截图，本机模型服务首先返回全英文结果：任务失败且原文保留；重试生成中文并使用引用式图片，确认正文渲染、便携导出、来源编号和搜索草稿／焦点。开发和打包验证结果见 [验证记录](../verification.md)。未重新调用用户的付费模型。
