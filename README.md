# 知序 · Windows 学习工作台（预览版 0.4.3）

本地资料库、跨教程关联、个人长期记忆和每次十题的复习工作台。已实际接入你下载在 `D:/Memo/mem0` 的开源 mem0ai 2.2.1，直接调用 `Memory.add`、`Memory.search` 和删除接口。未修改的第三方代码保存在 `vendor/mem0`，来源提交与 SHA256 见 `vendor/mem0/UPSTREAM.json`。使用用户配置的模型服务，不依赖 mem0 云 API。

## 使用

双击桌面“知序”或根目录“启动知序.cmd”，也可运行 `release/win-unpacked/Zhixu.exe`。可运行目录中的资源必须与 EXE 一起保留。

1. 点击“导入学习资料”，粘贴文本、导入 Markdown / 字幕、选择本地音视频，或提交公开直达视频链接。视频在后台处理，字幕优先；无可用字幕时本地转写，可提取时间点截图。默认勾选“导入后自动生成中文教程”，原文保存后继续调用已配置的模型；转写语言指原声语言，不是教程语言。取消勾选可只保存原文。纯音频请关闭截图。也可以直接“新建笔记”或“导入 Markdown 文件夹”。
2. 打开“模型与设置”，填写兼容 API 的基础地址、对话模型名称和自己的 API Key，保存后测试连接。地址应包含服务商要求的 `/v1` 等前缀。
3. 填写同一服务的 Embedding 模型，点击“同步 mem0 记忆”。mem0 从原文提取知识事实，也保存有来源的学习经历。设置中分别显示知识、关联、复习观察、历史提问和待同步数量。每次最多同步 24 项，仍有待同步项时可继续点击。未配置时仍可使用本地关键词搜索。
4. 打开资料，收藏选中内容或来源段落；AI 改写摘录需选择原文出处。可选择九种风格整理教程，支持图片的模型还可结合视频截图；旧正文保存在“版本历史”。用 `[[笔记名]]`、`[[笔记名#标题|显示文字]]`、`[[笔记名#^块编号]]` 或相对 `.md` 链接连接笔记，查看反向链接与引用图谱。正文 `#标签/子标签` 和笔记书签可筛选；搜索支持 `tag:`、`file:`、`path:`。语义关联仍由 mem0 召回、AI 分析，再由你确认。
5. 在“知识问答”中提问，回答提供资料出处；在“长期记忆”中维护讲解偏好、目标和经自己确认的进度。这些个人设置在问答、教程与出题前直接读取，无需向量化。
6. 在“复习与题库”选择整个知识库、某份资料或“仅我的收藏”，生成十道题。

0.4.3 修复手动导入视频后只显示英文转写的问题：此前导入完成只代表原文已保存，未自动调用教程生成。现在界面默认继续生成中文教程，并区分素材保存、教程生成与失败状态。模型失败时原文与截图保留，可只重试生成；取消或编辑资料后，迟到的模型结果不会覆盖已保存内容。已有英文资料可点击“AI 整理为中文教程”，无需重新下载。

0.4.1 已实测用户给出的 [B 站第 12 集“评估反射的影响”](https://www.bilibili.com/video/BV1AJen6SEVQ?p=12)：真实公开视频获取、本地转写、六张截图、真实在线生成，并在知序保存和重启读取。首次使用混元 Hy3；按用户后续要求切换为支持图片的 DeepSeek-V4.1-Flash，独立识图测试通过，并结合六张截图生成新版教程，包含 90 段来源、91 处有效引用。语音识别误差仍需结合原片核对。过程见 [真实验证报告](docs/audits/2026-10-25-bilibili-p12-live.md)。

0.4.2 又实测第 13 集“使用外部反馈”：视频获取、自动转写、六图及真实 DeepSeek 教程完成，保留 52 段来源和 58 处引用。首轮引用校验未通过，重试成功。修复模型 `frame:` 图片链接显示及导出，已知截图可插入正文，未知截图仍拒绝；导出嵌入图片并提前检查体积，不改变笔记链接身份。[第 13 集实测记录](docs/audits/2026-10-25-bilibili-p13-live.md)。

## 十题复习

- 每组 4 道单选、3 道多选、3 道简答，顺序随机；使用随机抽样的来源片段，适当增加近期错题涉及片段的权重。
- 每次向模型请求新题，同组和最近五组的相同题干会被拒绝；校验失败自动重试一次，仍失败不保存不完整题组。
- 资料须至少 200 字，题目必须携带有效来源。形式与出处校验无法保证模型的每一道题在知识上都正确，提交后应结合原文核对。
- 每题 10 分，总分 100；单选按正确答案计分，多选必须完全匹配，错选或漏选均为 0 分。
- 简答结合预先生成的评分要点，由 AI 给出 0–10 分和反馈。模型服务失败时保留草稿，重试即可。
- 交卷前不向界面提供正确答案、解析和评分要点；交卷后查看解析、来源和成绩。练习组与题库记录一起保存在本地。
- 输入简答时自动保存；正常关闭窗口前再次保存草稿。已交卷记录只读，重复提交不会重复计分。

## 数据与隐私

整个项目位于 `D:/rea-tools/video-knowledge-desktop`，双击根目录的“启动知序.cmd”即可运行。默认数据目录为项目旁的 `data`，当前是 `D:/rea-tools/video-knowledge-desktop/data`。其中包含 SQLite 主库、可重建的 Qdrant 本地向量索引、媒体副本 / 截图 / 任务、转写模型及加密凭据文件；桌面缓存与日志存放在 `data/app-state`。备份请先关闭应用，再复制整个数据目录。环境变量 `ZHIXU_DATA_DIR` 或命令行 `--data-dir=绝对路径` 可指定独立数据目录，命令行优先，设置页面会显示实际位置。

API Key 由 Electron `safeStorage` 使用 Windows 系统保护保存，不写入业务数据库或日志。在线生成、评分、问答及 Embedding 会将需要处理的内容发送给所配置的服务；本地保存不代表完全离线。Embedding 共用对话 API Key，应使用同一服务商或兼容网关。mem0 遥测关闭，其向量、历史与运行状态位于 `data/mem0`。原有资料和题库无需迁移，升级前数据库备份在 `data/backups`。

删除资料会删除其收藏、关联、含该来源的练习、引用该资料的问答及登记在该任务下的媒体副本 / 截图；原始选中文件和模型不受影响。编辑普通文本时，搜索片段重建，旧练习和问答清理；收藏标明来源已更新，可重新确认。视频 / AI 教程编辑保留原始来源。版本历史支持预览和完整恢复；删除后的旧链接不会误连到后来同名的新笔记。导出 Markdown 保留出处、时间点和受管理截图，可重新导入；不能用正文中的文件路径读取任意附件。

## 已实现与当前边界

已实现资料管理、收藏、来源检索、关键词 / 可选语义检索、关系建议与确认、带出处的问答、个人设置、完整十题练习与历史，以及上述笔记链接、图谱、标签、版本和媒体流程。[REA 对比与覆盖说明](docs/audits/2026-10-25-feature-parity.md) 区分实际证据、已验证行为与剩余差异。

公开直达入口支持 B 站 BV / 分 P、YouTube、抖音 `/video/` 与快手 `/short-video/`，实际下载仍受平台可访问性限制；不接受短链、播放列表、登录凭据或受限内容。可改用本地媒体或手工字幕。转写使用 CPU tiny 模型，首次需下载公共模型，准确率需核对；当前项目已缓存模型。单媒体最多 1 GiB / 4 小时，截图最多 6 张，单次教程生成最多 8 万字。Markdown 文件夹最多 500 文件 / 合计 40 MB，单文件 24 MB、正文 200 万字；导出不覆盖已有文件。

当前图谱表达明确引用与已确认关系，不自动证明知识推理。没有完整 Obsidian 插件 / 主题 / 附件兼容、云同步、发布、后台定时复习或自动画像。版本保留正文与出处，尚未逐版本保留所用模型 / 风格元数据。AI 补充和语音识别需核对，不能宣称完整复刻两个产品。

个人偏好、目标和自述进度由用户维护，同名更新后只读取当前有效版本，不进入 mem0 索引。升级时自动清理旧版个人设置向量，原始条目保留。不会根据一次阅读或一次练习自动判定已经掌握知识。

mem0 的学习经历包括：有原文证据且已经确认的资料关系、已完成练习的单题得分/作答/反馈、历史问题及引用出处。复习记录带时间并明确只代表当次表现；历史 AI 答案不作为知识写入。完整试卷、分数、原文和问答仍保存在 SQLite，可用于核对和重建索引。

问答和出题前会按需同步学习经历，并在当前来源范围内语义召回，用于衔接困惑、调整重点；新导入教程的知识抽取仍使用设置中的同步按钮。只问某份资料时，事实依据和学习经历限定于该资料；跨教程请选“整个知识库”。收藏专项只使用已选收藏片段。同步或检索失败会提示，原文与个人偏好仍可用于生成。界面显示本次使用的学习经历数量。

跨教程关联先通过 mem0 召回抽取出的知识事实，再回链原始片段，由 AI 判断关系。关键词检索作为独立补充；未安装上游可选的 spaCy / fastembed，因此 mem0 内部不启用这两项扩展。更换模型使用独立索引空间，需重新同步。同步失败不会影响原资料，失败片段可以重试。

## 开发与验证

Python 3.11 与 Node.js 24，在项目目录执行：

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.lock.txt
npm.cmd ci
npm.cmd run build
npm.cmd start
```

验证：

```powershell
npm.cmd test
npm.cmd run build
npm.cmd run smoke
node scripts/notebook-smoke.cjs
node scripts/media-tutorial-smoke.cjs
```

`scripts/smoke.cjs` 启动真实 Electron 窗口和本机测试 HTTP 服务，不调用收费在线模型。覆盖导入、收藏、直接读取偏好、系统加密密钥、真实 mem0 知识及三类学习经历召回、本地 Qdrant、十题生成、关闭时保存与重启恢复、评分、引用问答及删除。`notebook-smoke.cjs` 检查安全 Markdown、链接、标签 / 书签 / 图谱、版本恢复、系统对话框导入导出及失效收藏修复。设置 `ZHIXU_REAL_MEDIA` 为实际本地视频时，另验证真实转写 / 截图及后台进度不覆盖输入；使用项目的 `data/models` 模型缓存。测试数据置于 `.test-data`，不会混入正常知识库。验证数量与打包结果见 `docs/verification.md`。

构建 Windows 产物：

```powershell
npm.cmd run build:backend
npm.cmd run build
npm.cmd run pack
npm.cmd run dist:win
```

测试打包程序时可将 `ZHIXU_EXECUTABLE` 指向 `release/win-unpacked/Zhixu.exe` 后再运行 smoke。上述第 12 集教程已使用真实混元及 DeepSeek 图文服务验证；其他视频兼容性、真实在线出题与评分质量未全面验证。TokenHub 的指定 Hy3 / Hy4 / DeepSeek Flash 模型在结构化生成时使用官方支持的关闭深度思考参数，以免默认思考耗尽最终 JSON 输出及等待预算；其他服务不添加此参数。
