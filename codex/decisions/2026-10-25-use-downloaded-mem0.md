用户明确要求实际调用 mem0 代码。采用 D:/Memo/mem0 的 mem0ai 2.2.1，提交 b7ad69afda6b6ed030347c66d48a13e4de9dec08；未修改的包与许可证复制到 vendor/mem0，并作为本地 Python 依赖安装。上游源码与安装后的核心文件哈希一致性由测试验证。

Memory.add(infer=True) 提取教程知识，Memory.search 召回相关事实并回链来源段落，原生删除接口清理失效记忆。个人明确记忆使用 infer=False，避免再次推断用户原意。关系判断、确认、原始资料和题库继续由应用维护。

应用只适配模型传输接口，不重写 mem0 的抽取、去重、向量持久化与检索算法。保留既有 HTTPS、超时和凭据隔离。模型不配置或同步失败时，界面明确提示并保留原资料；关键词搜索仍可使用。

关闭遥测，全部状态存储在应用 data/mem0。不同模型配置使用独立空间。记录同步状态及来源版本，检查抽取事实与实际保存数量，避免上游部分失败被误报为成功。

未选择仅仿照算法自建记忆；未使用 mem0 云端。真实模型服务质量仍需要用户配置 API 后验证，测试只替换外部模型响应。
