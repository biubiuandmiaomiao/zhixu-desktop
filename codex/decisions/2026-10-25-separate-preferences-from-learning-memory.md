# 个人偏好直接读取，学习经历进入 mem0

用户确认：个人偏好只需在生成时读取相关内容，不参与知识关联。原本只有知识和个人记忆进入 mem0 的划分不足以支持学习经历回忆，应让已确认关系、复习表现和历史提问共同参与检索。

保留 SQLite 作为完整记录及确认状态的依据；mem0 存储有来源的知识与学习经历。偏好、目标和用户确认进度直接读取当前有效条目，教程、问答、出题使用它们；旧 personal 向量离线清理而原始条目保留。学习经历作为有时间的观察，不据此推断长期能力；历史问答仅索引问题及原文出处，不将 AI 回答抽取为事实。

未采用全部记录仅存 mem0：准确成绩、完整试卷、关系方向和更正删除依赖可核对的结构化原始记录。也未保持三类经历完全不参与 mem0：那样无法根据当前主题召回之前的困惑与练习表现。

代价是维护派生索引版本与来源映射，以及同步/检索失败降级。范围见 docs/superpowers/specs/2026-10-25-learning-memory-design.md，实施见 docs/superpowers/plans/2026-10-25-learning-memory.md。此决定取代 2026-10-25-use-downloaded-mem0.md 中将个人明确记忆存入 mem0 的部分；固定上游源码、关闭遥测和本地数据位置继续保留。
